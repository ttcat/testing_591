Q&A

看房前，先把常見問題回答完。

可以養寵物嗎？

可以養貓，寵物條件會正式寫進租約。其他寵物需另行確認。

可以申請租屋補助、報稅嗎？

可以。屋主自租，會依法配合符合資格的租補與報稅需求。

租金包含哪些費用？

目前方案包含水費、天然瓦斯費與既有網路；電費依分表與台電實際帳單方式計算，不另加價賺電費。

有管理費或仲介費嗎？

沒有管理費。屋主自租，無仲介費。

離捷運站多遠？

步行約15分鐘。巷口有 YouBike；平常騎車、YouBike 或在中和一帶活動的人會更適合。

5樓有洗衣、烘衣嗎？

有，全新 LG 洗衣＋熱泵式乾衣設備已安裝。

5樓可以開伙嗎？

可以，有完整廚房與天然瓦斯。

6樓可以開伙嗎？

6樓沒有完整廚房，適合外食為主的租客。

家具不喜歡可以搬走嗎？

明顯可移動家具可在簽約前討論移除；固定櫃體與設備則維持。

需要辦租約公證嗎？

5樓目前規劃租約公證；實際內容會在簽約前一次說明。

屋主會常常進屋嗎？

不會。非漏水、火災等緊急狀況，會事先聯絡並約時間。

適合什麼樣的租客？

重視空間、安靜、可養貓，且能接受無電梯與非捷運第一排的人。希望穩定長住、彼此簡單好溝通。
